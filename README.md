# DJ23

> A modern web-based DJ mixing interface 🎧

## Features

- **Dual Deck Interface**: Load and mix tracks on two virtual decks
- **Professional Mixing Tools**: EQ, filters, effects (reverb, delay, phaser, flanger)
- **Beat Matching**: BPM detection and sync capabilities
- **Vinyl-style Controls**: Scratch and pitch bend functionality
- **Sound Pad**: Trigger sound effects during your mix
- **Recording**: Capture your mix and download as audio file
- **Responsive Design**: Works on desktop and mobile devices

## Recording Feature

The recording functionality captures the master output of your mix in real-time:

1. Click the **REC** button to start recording
2. Mix your tracks, use effects, and play sound pad samples
3. Click **REC** again to stop recording
4. Click **Download** to save your mix

**Note**: Recordings are saved in WebM format for broad browser compatibility. To convert to MP3:
- Use online converters like [CloudConvert](https://cloudconvert.com) or [Convertio](https://convertio.co)
- Use audio software like [Audacity](https://www.audacityteam.org) (free)
- Use command-line tools like FFmpeg

## Setup

- Clone, fork or download this repository
- Install dependencies: `npm install`
- Start the development server: `npm run dev`
- Open your browser and go to [localhost:8080](http://localhost:8080)
